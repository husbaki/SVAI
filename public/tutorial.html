Как пользоваться HyperWarp

← Открыть сайт · API / Swagger

  1. Открой окно памяти. Если скрыто — нажми Show memory. Hide window или Esc скрывает окно без удаления данных.
  2. В поле Project выбери itsdangerous, httpx или django.
  3. Во вкладке Query оставь Hybrid, введи вопрос и нажми Ask или Ctrl+Enter. Первый запрос может ждать загрузки Qwen.
  4. Для первого теста: How does Signer.validate handle an invalid signature? Ожидаемый ответ: False. Для HTTPX: What exception does Response.raise_for_status raise on an error status?
  5. Справа открой найденный источник. Это настоящий текст функции; ссылка подтверждает источник, но сама по себе не гарантирует верность объяснения.
  6. Compare variants сравнивает доступные live-режимы. Вкладка Compare показывает сохранённый эксперимент на 61 вопросе, а не новые измерения текущего запроса.
  7. Во вкладке Memory загрузи папку с исходниками или документами. Повторная загрузка того же пути обновляет запись. Изменение запечённых источников отключает старый hybrid: API явно использует RAG до нового обучения.
  8. Во вкладке Memory нажми New document для создания или Edit рядом с записью для редактирования. В окне редактора доступны Save и Delete. Также можно использовать панель документов backend или Swagger. Данные сохраняются в SQLite после перезапуска.

Что означает Bake

Проверка готового снимка и обучение — разные операции. Если веса соответствуют исходникам, снимок можно активировать. Автоматическое обучение нового корпуса пока не реализовано: сервис не рисует фиктивный прогресс.

Проверенный результат

Hybrid: 46/61 точных ответов; по Django — 17/21. Это выборка вопросов. Система ошибается, особенно на отсутствующих знаниях и новых задачах. Проверяй важные выводы по коду и тестам.
