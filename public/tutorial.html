Why did the old demo say False?
It displayed a raw Python return value. For Signer.validate, False means that the signature did not pass validation. The new interface explains that behavior first. The original return value remains under Technical details. False does not mean the same thing for every function.

Other screens

Sources: upload files, add a document, or edit/delete a record. Changes refresh retrieval. When a source no longer matches the trained memory, the service explicitly switches to live retrieval.

Results: inspect the saved evaluation on 61 questions. These are recorded experimental results, not a fresh test of your current query.

Read-only costs

Costs cover processing a question, retrieving or reading memory, and generating an answer. The charts exclude training, baking, document updates, index construction and cold start. Per-query costs use measured service time and an assumed GPU hourly price; they are estimates, not a cloud invoice.

Advanced options

Hybrid is selected automatically when its source snapshot matches. Expand Advanced options only to select RAG or compare live modes. You do not need to change these settings for the walkthrough.

Hide window or Esc hides the workspace. Show memory restores it without losing your question.
